# AI-assisted development disclosure

Generative AI was used as a development assistant during parts of Metaphor Agreement Studio's implementation and documentation. Assistance included code drafting, refactoring suggestions, test scaffolding, debugging support, documentation drafting, and review of proposed changes.

Human contributors defined the research problem, specified the methodological requirements, made the core design and statistical decisions, selected acceptance criteria, reviewed and edited AI-assisted outputs, and repeatedly validated the software against real and synthetic research workflows.

The project maintainers remain responsible for the accuracy, originality, licensing, scientific interpretation, and behavior of the public repository. A journal submission will provide the tool/model/version detail required by the target venue's AI-disclosure policy.
