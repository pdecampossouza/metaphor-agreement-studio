# Research-software publication roadmap

This public repository begins the open-development record for Metaphor Agreement Studio.

## Near-term goals

- Maintain issues and changes publicly.
- Keep automated tests and cross-platform CI green.
- Publish tagged releases with changelog entries.
- Add external-user feedback and reproducible tutorials.
- Archive stable releases with Zenodo and record the DOI in `CITATION.cff`.
- Maintain a concise software paper separately from study-specific empirical papers.

## JOSS-oriented readiness

The Journal of Open Source Software currently expects sustained public development history, evidence of research use, good open-source practices, tests/CI, clear documentation, and a maintainable software design. This repository should therefore accumulate real public iteration rather than being treated as a one-time code deposit.

The empirical paper that uses Metaphor Agreement Studio can be published independently. A later software paper should focus on the reusable research-software contribution, architecture, validation, and documented research impact rather than duplicate the empirical study.
