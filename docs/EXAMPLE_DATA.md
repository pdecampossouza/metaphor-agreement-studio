# Example data

The workbook `imports/Teste de Concordancia - Revisor Eduardo.xlsx` is included as an audited example for exercising the software workflow.

It is intentionally **not a complete doctoral-study dataset**. It should be used to demonstrate workbook discovery, validation decisions, source aggregation, rater comparison, statistical calculations, figures, and report generation. Values obtained from the example workbook are software-validation/example results and must not be presented as substantive findings from the doctoral research.

The SHA-256 value of the distributed example is recorded in `imports/source_manifest.sha256` so that changes to the example can be detected explicitly.

Researchers should keep their own source workbooks outside version control unless they have a clear data-sharing basis and redistribution rights.
