Metaphor Agreement Studio 1.0

Inter-rater analysis for lexical metaphor annotation — local, researcher-controlled, and reproducible.

Windows

  1. Extract the complete ZIP.
  2. Double-click START_METAPHOR_STUDIO_WINDOWS.bat.
  3. On the first run, allow a few minutes for the private environment to be prepared.
  4. Use the browser application normally.
  5. Double-click STOP_METAPHOR_STUDIO_WINDOWS.bat when finished.

Optional: CREATE_DESKTOP_SHORTCUT_WINDOWS.bat.

macOS

  1. Extract the complete ZIP.
  2. Leave Metaphor Agreement Studio.app inside the extracted folder.
  3. Double-click the app.
  4. If macOS blocks the unsigned app on first launch, right-click it, choose Open, then confirm Open.
  5. Use STOP_METAPHOR_STUDIO_MAC.command when finished.
Research safeguard: the original workbook is never modified. Detection and inspection do not silently validate data. Multi-sheet workbooks require an explicit worksheet role, and synthetic/example sheets never enter research results.

Bráulio multi-sheet workbook

When testing Testes de concordancia - Braulio.xlsx, assign a role to each worksheet before continuing:

  1. Dois avaliadores → Study data for the real two-rater workflow.
  2. Mais de dois avaliadores → Synthetic / example data. Bráulio supplied these values only to test the multi-rater model.

Synthetic/example worksheets are excluded from validated research statistics.

To test the 3+ rater model itself, you may temporarily reverse the two roles. Expected synthetic control values are Fleiss' Kappa ≈ 0.69125 and Cochran's Q = 135.0. They are not doctoral research findings.

Recommended first workflow

  1. Open Overview and choose the detected workbook.
  2. In Data Validation, first assign worksheet roles when more than one annotation worksheet is present; then review tables, raters, mappings, normalization proposals, and aggregate-source proposals.
  3. Validate the dataset.
  4. Explore Agreement, Disagreement Review, categories, sources, raters, and Statistical Analysis.
  5. Choose No reference, Reference rater, or Expert benchmark as appropriate.
  6. In Statistical Analysis, use Generate Comparison Report (PDF) to create a multi-page scientific comparison report for the active scope.
  7. Save as a Research Project if the work should persist.
  8. Use Figures, LaTeX & Reporting, and Export Center for research outputs.
