# Security Policy

Metaphor Agreement Studio is a local research application and does not require a cloud account or remote database. Security issues can still matter because the application reads user-supplied workbooks and writes local project artifacts.

Please do not publish exploit details or private research data in a public issue. If GitHub Private Vulnerability Reporting is enabled for this repository, use the repository Security tab. Otherwise, open a minimal public issue stating that you have a security concern and wait for maintainer guidance before sharing sensitive technical details.

Supported security fixes target the current public release and active development branch.
